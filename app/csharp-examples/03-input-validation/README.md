# Example 3: Console Application with Input Validation

In this example, you'll learn how GitHub Copilot can help you build a console application with robust input validation.

## Tasks

### Task 1: Create an Input Validator Class

1. Create a new file called `InputValidator.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create an InputValidator class with methods to validate different types of input
   // Add methods to validate: email addresses, phone numbers, dates, numeric ranges, and text length
   // Each method should return a bool indicating whether the input is valid
   // Include helpful error messages for invalid input
   ```
3. Let GitHub Copilot generate the class for you

### Task 2: Create a User Registration System

1. Create a new file called `UserRegistration.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a User class with properties for Username, Email, Password, DateOfBirth, and PhoneNumber
   // Add a UserRegistrationService class that handles user registration
   // Include validation for all user fields using the InputValidator
   // Store registered users in a collection
   ```
3. Let GitHub Copilot generate the class for you

### Task 3: Create a Console Interface

1. Create a new file called `Program.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a console application that allows users to register new accounts
   // The program should prompt for each piece of information with clear instructions
   // Validate each input and display appropriate error messages if validation fails
   // After successful registration, display a summary of the registered user information
   // Allow the user to register multiple accounts in a single session
   ```
3. Let GitHub Copilot generate the code for you

## GitHub Copilot Tips

- Ask Copilot to add more sophisticated validation rules
- Request Copilot to improve the user experience with color-coded console messages
- Try having Copilot add password strength requirements
- Ask for additional validation methods for specific use cases

## Learning Objectives

After completing this example, you should be able to:
- Use GitHub Copilot to create robust input validation logic
- Understand how to prompt Copilot for user interaction code
- Build a complete console application with validation and error handling
