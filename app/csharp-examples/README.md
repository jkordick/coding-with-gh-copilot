# Learning GitHub Copilot with C#

Welcome to the C# learning path for GitHub Copilot! This guide will help you learn how to leverage GitHub Copilot to enhance your C# development workflow.

## Prerequisites

Before you begin, make sure you have the following:

1. [GitHub Copilot](https://copilot.github.com/) access
   - If you're a Microsoft employee, request access [here](https://repos.opensource.microsoft.com/orgs/MicrosoftCopilot)
   - For others, GitHub Copilot is available for purchase (free for students and teachers!)

2. Development environment:
   - [.NET SDK](https://dotnet.microsoft.com/download) (6.0 or later recommended)
   - Code editor with GitHub Copilot extension:
     - [Visual Studio Code](https://code.visualstudio.com/) with [C# extension](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp) and [GitHub Copilot extension](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
     - [Visual Studio](https://visualstudio.microsoft.com/) with [GitHub Copilot extension](https://marketplace.visualstudio.com/items?itemName=GitHub.copilotvs)
     - [JetBrains Rider](https://www.jetbrains.com/rider/) with [GitHub Copilot plugin](https://plugins.jetbrains.com/plugin/17718-github-copilot)

## Learning Path Overview

This learning path consists of 5 examples that will help you understand how to use GitHub Copilot with C#:

1. **Basic C# Syntax and Structure**: Learn how GitHub Copilot can help with creating classes, methods, and properties
2. **Working with Collections and LINQ**: Discover how Copilot can assist with data manipulation using LINQ
3. **Console Application with Input Validation**: Build a simple application with input validation
4. **Rock, Paper, Scissors Game**: Create a complete game implementation
5. **Unit Testing**: Learn how GitHub Copilot can help you write effective unit tests

## How to Use This Learning Path

Each example directory contains:
- A README.md file explaining the concepts and tasks
- Starter code (where applicable)
- Solution code that demonstrates the completed example

To get the most out of GitHub Copilot:
1. Read the README.md in each example directory
2. Try to complete the tasks using GitHub Copilot
3. Compare your solution with the provided solution

## Tips for Working with GitHub Copilot and C#

- **Be specific in your comments**: The more context you provide, the better suggestions you'll get
- **Use natural language**: Write comments that clearly explain what you want to achieve
- **Iterative approach**: If you don't get the exact code you want, keep refining your comments
- **Leverage intellisense**: Use Copilot alongside your editor's intellisense for the best experience
- **Learn from suggestions**: Even if you don't use a suggestion directly, you can learn from the code patterns Copilot provides
