# Example 5: Unit Testing in C#

In this example, you'll learn how GitHub Copilot can help you write effective unit tests for your C# code.

## Tasks

### Task 1: Create a Calculator Class

1. Create a new file called `Calculator.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a Calculator class with methods for basic arithmetic operations
   // Add methods for addition, subtraction, multiplication, division
   // Add a method to calculate the square root of a number
   // Add input validation and appropriate exception handling
   ```
3. Let GitHub Copilot generate the class for you

### Task 2: Create Unit Tests for the Calculator

1. Create a new file called `CalculatorTests.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create unit tests for the Calculator class using xUnit
   // Test each arithmetic operation with various inputs
   // Include tests for edge cases and exceptions
   // Add appropriate test categories and meaningful test names
   ```
3. Let GitHub Copilot generate the tests for you

### Task 3: Create a String Utility Class

1. Create a new file called `StringUtility.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a StringUtility class with methods for common string operations
   // Add methods for reversing a string, checking if a string is a palindrome
   // Add a method to count occurrences of a substring
   // Add a method to convert a string to title case
   ```
3. Let GitHub Copilot generate the class for you

### Task 4: Create Unit Tests for the String Utility

1. Create a new file called `StringUtilityTests.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create unit tests for the StringUtility class using xUnit
   // Test each string operation with various inputs
   // Include tests for edge cases such as empty strings, null inputs
   // Use data-driven tests to check multiple inputs with a single test method
   ```
3. Let GitHub Copilot generate the tests for you

## GitHub Copilot Tips

- Ask Copilot to add test cases for specific edge cases
- Request Copilot to add code coverage annotations
- Try having Copilot generate mocks for dependencies
- Ask for different test patterns (e.g., Arrange-Act-Assert, Given-When-Then)

## Learning Objectives

After completing this example, you should be able to:
- Use GitHub Copilot to generate unit tests for C# code
- Understand how to prompt Copilot for specific testing scenarios
- Learn how Copilot can help with test-driven development
