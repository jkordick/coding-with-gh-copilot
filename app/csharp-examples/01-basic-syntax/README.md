# Example 1: Basic C# Syntax and Structure

In this example, you'll learn how GitHub Copilot can help you write basic C# code including classes, methods, properties, and more.

## Tasks

### Task 1: Create a Person Class

1. Create a new file called `Person.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a Person class with properties for FirstName, LastName, Age, and Email
   // Include a constructor that accepts all properties
   // Add a method to return the full name
   // Add validation to ensure Age is not negative
   ```
3. Let GitHub Copilot generate the class for you

### Task 2: Create a Student Class

1. Create a new file called `Student.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a Student class that inherits from Person
   // Add properties for StudentId and GradePointAverage
   // Override the ToString method to include all properties
   // Add a method to determine if the student is in good standing (GPA >= 2.0)
   ```
3. Let GitHub Copilot generate the class for you

### Task 3: Create a Course Class

1. Create a new file called `Course.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a Course class with properties for CourseId, Title, Credits, and Instructor
   // Include a list of enrolled students
   // Add methods to enroll and unenroll students
   // Add a method to calculate the average GPA of enrolled students
   ```
3. Let GitHub Copilot generate the class for you

### Task 4: Create a Program.cs File

1. Create a new file called `Program.cs`
2. Add a comment describing what you want to create:
   ```csharp
   // Create a Program class with a Main method
   // Create several Person objects
   // Create several Student objects
   // Create a Course object and enroll some students
   // Display information about all objects
   ```
3. Let GitHub Copilot generate the code for you

## GitHub Copilot Tips

- Try modifying the comments to see how Copilot's suggestions change
- Ask Copilot to add XML documentation comments to your classes and methods
- If you're not satisfied with the generated code, try rewording your comment or adding more details
- Use Copilot to add validation logic for properties

## Learning Objectives

After completing this example, you should be able to:
- Use GitHub Copilot to generate C# classes and methods
- Understand how the quality of your comments affects Copilot's suggestions
- Leverage Copilot to implement common patterns like inheritance and property validation
